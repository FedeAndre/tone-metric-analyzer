Tone-Metric Analyzer v0.16.1

Dissertation-first Levels reconstruction with derived waves, pivots, and trees. v0.16.1 separates notation/OMR preprocessing from the Chapter 1/4 Levels mathematics, renders parenthetical structural articulations as real no-attack Level points, completes each rhythmic denomination before moving finer, and uses explicit meter profiles rather than inferring arity from note spacing. Tuplet-voice attacks are excluded from the strict dissertation core; they are not treated as a generic 4/4 ternary rule.

Attack timing is never inferred from PDF geometry. Parenthetical positions are placed only after score time is fixed. Waves reuse validated attack/structural positions, pivots reuse only validated wave anchors, and trees reuse only actual-attack wave anchors. No tree can create or move musical events, Levels, wave points, or pivots.
