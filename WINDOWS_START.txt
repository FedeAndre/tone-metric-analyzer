Tone-Metric Analyzer v0.16.3 — Windows PowerShell

IMPORTANT
- Extract v0.16.3 into a NEW folder. Do not overwrite v0.16.2.
- Stop any older Tone-Metric server first (Ctrl+C in its PowerShell window).
- Open PowerShell in THIS folder (the one containing requirements.txt and app.py).

Run:

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe validate_release.py
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000

Then verify the running build BEFORE uploading a PDF:

Invoke-RestMethod http://127.0.0.1:8000/api/status

Expected identifying fields:
version    : 0.16.3
omr_driver : step-page-save

Then open:
http://127.0.0.1:8000

For PDF analysis, set AUDIVERIS_CMD to the real Audiveris executable before starting Uvicorn, for example:

$env:AUDIVERIS_CMD = "C:\Path\To\Audiveris.exe"
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000

v0.16.3 required PDF driver:
Audiveris -batch -step PAGE -save -output <session> -- <score.pdf>

The required PDF path does NOT request -transcribe and does NOT request -export.
